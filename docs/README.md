# RuleForge Documentation

| Folder / file | What it holds | Audience |
|---|---|---|
| [`roadmap.md`](roadmap.md) | What's done, what's next, and the backlog — start here | Everyone |
| [`guides/`](guides/) | How to use RuleForge: [quick start](guides/quick-start.md), [JSON rule format](guides/json-rules.md) | Library users |
| [`specs/`](specs/) | One design spec per implemented phase, each with a **Deviations** section | Contributors |
| [`proposals/`](proposals/) | Designs written but not yet scheduled | Contributors |
| [`archive/`](archive/) | Historical reports and the original roadmap, kept as-is | Reference only |

Specs are named `YYYY-MM-DD-<topic>-design.md`. When a spec's design changes during implementation,
the change is recorded in its Deviations section before the PR merges.
